# Contributing

Issues and pull requests are welcome. Please keep changes focused and describe how they affect keyboard, mouse, and controller users.

## Bug reports

Include the helper version, Windows version, OceanTriRecomp version, controller model and connection mode (if relevant), the exact steps to reproduce, and the relevant lines from the helper console. Do not attach game images or data files unless they are needed to explain the issue.

## Changes

1. Open an issue for larger changes so the expected behavior can be discussed first.
2. Build the x64 Release target with the commands in the README.
3. Describe what changed and the hardware/input cases you were able to check.

Please do not bundle game files, disc images, save data, or third-party binaries in pull requests.
